# Crafted Commerce

Build a premium, fully functional e-commerce website with a unique animated website-building introduction.



MAIN CONCEPT:

When a visitor opens the website for the first time, they should experience an animation that looks like multiple designers are collaboratively building the website in real time.



1. Website Building Animation



- Show 3–5 animated mouse cursors with different colors.

- Each cursor should have a small name label.

- Make the cursors move naturally around the screen.

- Show realistic clicking, dragging, selecting and typing animations.

- Website sections should visually assemble themselves in real time.

- Build the navbar, hero section, product cards, categories, banners and footer.

- Add smooth transitions and realistic design-editor-style interactions.



2. Automatic Scrolling



- Automatically scroll down slowly as the website is being assembled.

- Reveal each new section progressively.

- Keep the animation smooth and cinematic.

- Show a small progress indicator such as "Building your shopping experience... 65%".

- The animation should feel premium and futuristic.



3. Animation Completion



- Once all website sections are assembled, show a short finishing animation.

- Display "Your Shopping Experience Is Ready".

- Smoothly transition into the actual functional website.

- Remove all building cursors and animation overlays.

- Enable normal scrolling and all website interactions.



4. Fully Functional E-commerce Website

After the animation, the website must work like a real online store.



Include:



- Modern navigation bar.

- Hero banner.

- Product categories.

- Featured products.

- Product details pages.

- Product search and filters.

- Add to cart.

- Shopping cart.

- Wishlist.

- User authentication.

- Checkout page.

- Customer order tracking.

- Responsive mobile and desktop layouts.

- Admin dashboard for managing products and orders.



5. Technical Requirements



- Use React, TypeScript and Tailwind CSS.

- Use Framer Motion for animations.

- Use Supabase for authentication, database and backend.

- Keep the building animation separate from the actual store functionality.

- Do not block website functionality after the animation.

- Use sessionStorage so the introduction plays once per browser session.

- Add a Skip Animation button.

- Support mobile devices and touch screens.

- Optimize performance and avoid unnecessary loading.



IMPORTANT:

The animation must not be a video. It must be a real, interactive CSS/JavaScript animation with multiple independently moving cursors and dynamically revealed website sections.



The final result must be a real working e-commerce website, not just a visual prototype.
